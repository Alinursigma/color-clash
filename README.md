# Color Clash

Мини-игра на память, глазомер и чувство цвета.

Статический сайт: `index.html`, `styles.css`, `app.js`, `color.js`, `i18n.js`, `avatar.svg`.

## Деплой

Проект на Vercel (`color-clash`) подключён к этому репозиторию:

- push в `main` → production-деплой
- pull request → preview-деплой

Локальный запуск: открыть `index.html` в браузере или `npx serve .`
